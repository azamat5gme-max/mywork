# Bilim

Учебное приложение для школьников Кыргызстана. *Bilim* по-кыргызски значит «знание».
При первом входе ученик выбирает язык: **кыргызский**, **русский** или **английский**. Сменить язык можно кнопкой «КЫР / РУС / ENG» вверху или в профиле.

- **Тесты:** вопросы в стиле ОРТ по математике, истории, географии, английскому и естествознанию
- **Карточки:** кыргызские, русские и английские слова, формулы, термины
- **Доска идей:** ученики делятся советами по учёбе и ставят лайки
- **Фокус-таймер:** 25 минут учёбы, 5 минут отдыха
- **Восхождение:** каждый XP поднимает тебя выше, от Бишкека (800 м) до пика Победы (7439 м)
- Цель на день, серии, значки, вопрос дня, светлая и тёмная тема

## Что лежит в папке

| Файл | Зачем нужен |
|---|---|
| `index.html` | Всё приложение: дизайн, тексты, вопросы и код |
| `manifest.webmanifest` | Позволяет установить сайт на телефон как приложение |
| `sw.js` | Делает так, чтобы приложение работало без интернета |
| `firebase-config.js` | По желанию: делает доску идей общей для всех |
| `firestore.rules` | Правила безопасности для общей доски идей |
| `icons/` | Иконки приложения |

## 1. Открыть на компьютере

Дважды нажми на `index.html`. Он откроется в браузере, и всё будет работать.

Две вещи заработают только после того, как сайт будет в интернете (шаг 2): установка на телефон и работа без интернета.

## 2. Выложить в интернет бесплатно

Выбери один способ. Если сайт спросит возраст или банковскую карту, попроси помочь родителей или учителя.

**Способ А: Netlify Drop (самый простой)**
1. Открой **app.netlify.com/drop**.
2. Перетащи туда всю эту папку.
3. Ты получишь ссылку вида `https://что-то.netlify.app`. Создай бесплатный аккаунт, чтобы сайт не удалился.

**Способ Б: GitHub Pages**
1. Создай бесплатный аккаунт на **github.com**.
2. Создай новый репозиторий `bilim` и загрузи туда все файлы из этой папки.
3. Открой **Settings → Pages**. В пункте «Branch» выбери `main` и `/ (root)`, нажми **Save**.
4. Через минуту приложение будет по адресу `https://ТВОЙ-НИК.github.io/bilim/`.

## 3. Установить на телефон

Открой свою ссылку на телефоне.

- **Android (Chrome):** нажми меню **⋮** → **Установить приложение** (или «Добавить на главный экран»). Ещё можно нажать **Установить** внутри Bilim.
- **iPhone (Safari):** нажми **Поделиться** → **На экран «Домой»**.

Теперь у Bilim есть своя иконка, оно открывается на весь экран и работает без интернета. (Для доски идей интернет нужен.)

## 4. Общая доска идей (по желанию, бесплатно)

Без этого шага идеи сохраняются только на телефоне каждого ученика. С Firebase все видят одну общую доску.

1. Открой **console.firebase.google.com** и нажми **Create a project**. Назови его `bilim`. Google Analytics можно выключить.
2. В меню слева открой **Build → Firestore Database** → **Create database**. Выбери ближайший регион и **production mode**.
3. Открой вкладку **Rules**. Удали всё, что там написано, вставь всё из файла `firestore.rules` и нажми **Publish**.
4. Открой **Build → Authentication** → **Get started** → **Sign-in method** → **Anonymous** → включи → **Save**.
5. Нажми на шестерёнку → **Project settings**. В разделе «Your apps» нажми кнопку **</>** (Web), придумай название и нажми **Register app**.
6. Firebase покажет `firebaseConfig` с `apiKey`, `authDomain`, `projectId` и другими значениями. Скопируй их в `firebase-config.js`.
7. Загрузи файлы на сайт ещё раз (шаг 2).

Писать на доске может любой, у кого есть ссылка, поэтому иногда проверяй её. Чтобы удалить запись, открой в Firebase **Firestore Database → ideas** и удали её там.

## 5. Выложить в Google Play (по желанию)

1. Сначала выложи приложение в интернет (шаг 2).
2. Открой **pwabuilder.com**, вставь свою ссылку и нажми **Start**.
3. Выбери **Package for stores → Android**. Получится файл, который принимает Google Play.
4. Аккаунт разработчика Google Play стоит $25 один раз, и его владельцу должно быть 18 лет, поэтому создать его нужно родителям.

## 6. Как менять приложение самому

Открой `index.html` в редакторе кода (например, VS Code).

- **Тексты на трёх языках:** найди `const STR`. Внутри три блока: `ky` (кыргызский), `ru` (русский) и `en` (английский). У каждого текста одинаковое имя во всех блоках.
- **Добавить вопрос в тест:** найди `const QUIZ`. Каждый вопрос выглядит так:
  ```js
  { a: 2, o: ["вариант A", "вариант B", "вариант C", "вариант D"],
    ky: ["Суроо кыргызча?", "Түшүндүрмө."],
    ru: ["Вопрос по-русски?", "Объяснение."],
    en: ["Question in English?", "Explanation."] },
  ```
  `a` — номер правильного ответа: **0 = A, 1 = B, 2 = C, 3 = D**.
  Если варианты ответов на двух языках разные, убери `o` и добавь варианты третьим пунктом: `ru: ["Вопрос?", "Объяснение.", ["A", "B", "C", "D"]]`.
- **Добавить карточки:** найди `const WORDS` (слова на кыргызском, русском и английском), `const ENG`, `const MATHF` или `const SCI`.
- **Изменить уровни:** найди `const LEVELS`.
- **Изменить название:** найди `Bilim` в `index.html` и `manifest.webmanifest`.
- **Изменить цвета:** цвета в самом начале блока `<style>` (`--sun`, `--gold`, `--glacier` и другие).

После любых изменений открой `sw.js` и увеличь номер версии: `bilim-v3` → `bilim-v4` и так далее. Тогда телефоны скачают новую версию.
